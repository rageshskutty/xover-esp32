# T23 — PCM5122 TDM register write table

**Objective:** produce the ordered register writes that put one PCM5122 into TDM, 32-bit words, with a given data offset. Pure host logic; no I2C, no ESP-IDF.
**Paths:** `firmware/components/pcm5122/internal/pcm5122_regs.h`, `firmware/components/pcm5122/pcm5122_regs.c`, `host/tests/test_pcm5122_regs.c`, host and component source registration. Add `firmware/main` as a private include dir of the test target only (it supplies `board_config.h`).
**Datasheet source (S1):** TI SLAS763C, 12.1.1 Register Map (register 0 is the page select in every page) and 12.1.1.2 Page 0, Table 83 (Reg 0x28: AFMT bits 5:4, ALEN bits 1:0) and Table 84 (Reg 0x29: AOFS, 8 bit, offset in BCK from the start of the audio frame).
**API (exact):**
```c
#define PCM5122_REG_PAGE_SELECT 0x00U
#define PCM5122_REG_AUDIO_FORMAT 0x28U
#define PCM5122_REG_AUDIO_OFFSET 0x29U
#define PCM5122_AFMT_TDM_DSP 0x01U
#define PCM5122_ALEN_32BIT 0x03U
#define PCM5122_AUDIO_FORMAT_TDM_32 ((PCM5122_AFMT_TDM_DSP << 4) | PCM5122_ALEN_32BIT)
#define PCM5122_TDM_WRITE_COUNT 3U
#define PCM5122_TDM_OFFSET_MAX 255U
typedef struct { uint8_t reg; uint8_t val; } pcm5122_reg_write_t;
int pcm5122_tdm_writes(uint32_t offset_bck, pcm5122_reg_write_t out[PCM5122_TDM_WRITE_COUNT]);
```
**Behavior:** return -1 and leave `out` unchanged if `out` is NULL or `offset_bck > 255`. Otherwise fill `out` with `{0x00, 0x00}`, `{0x28, 0x13}`, `{0x29, offset_bck}` in that order and return 0. No other registers, no delays, no clock or PLL writes (the part auto-configures its clocks from SCK/BCK/LRCK, SLAS763C 8.3.6.2).
**Test:** committed but unregistered `host/tests/test_pcm5122_regs.c`. Register it, confirm the baseline fails (missing header or undefined `pcm5122_tdm_writes`), implement, rerun. Covers offsets 0, 1, 64, 128, 255, the three offsets in `board_config.h`, 256 and UINT32_MAX rejected with `out` untouched, and NULL `out`.
**Open hardware item (do not resolve here):** whether the offset is 0/64/128 or 1/65/129 on the real boards (`docs/hw-verification-notes.md` section 2, item 2). The table takes the offset as an argument so that question never changes this code.
**Size:** 15–40 production LOC. `pcm5122` is a CODEOWNERS path. Regression: do not modify registered tests; full host suite and `python tools/check.py` stay green. Three attempts maximum; diff-only report.
