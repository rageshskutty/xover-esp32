# T27 — tdmout ESP-IDF TDM driver (target only)

**Objective:** ESP-IDF v5.5.6 I2S TDM master transmitter driver for the 6-channel active crossover. Initializes I2S0 in 8-slot 32-bit TDM mode with a 1-BCK short sync, applies a low-level register override to enforce MCLK = BCLK = 12.288 MHz (256x fS, bck_div = 1), starts and stops DMA transmission, and provides blocking frame writes. Target-only driver; playback loop and `main.c` wiring belong to a later bring-up card.

**Depends on:** T17 (tdm_pack, merged), T26 (merged).

**API (exact):**
```c
#pragma once

#include <stddef.h>
#include <stdint.h>
#include "esp_err.h"

/* Initialize I2S0 in TDM master TX mode (48 kHz, 8x32-bit slots, slot mask 0x3F). */
esp_err_t tdmout_init(void);

/* Start I2S TX channel DMA transmission. */
esp_err_t tdmout_start(void);

/* Stop I2S TX channel DMA transmission. */
esp_err_t tdmout_stop(void);

/* Deinitialize and release I2S channel resources. */
esp_err_t tdmout_deinit(void);

/*
 * Write interleaved 8-slot 32-bit frames to I2S TX DMA buffer.
 * Blocking call. timeout_ms: milliseconds to wait (or UINT32_MAX for portMAX_DELAY).
 * bytes_written: optional out-pointer for actual bytes transferred.
 * Validates non-NULL, non-zero, and 32-byte frame boundary alignment.
 */
esp_err_t tdmout_write(const void *src, size_t size_bytes, size_t *bytes_written, uint32_t timeout_ms);
```

**Behavior:**
1. `tdmout_init`:
   - Returns `ESP_ERR_INVALID_STATE` if already initialized.
   - Enforces compile-time checks: `XOVER_SAMPLE_RATE_HZ == 48000`, `XOVER_TDM_SLOT_BITS == 32`, `XOVER_TDM_SLOTS_PER_FRAME == 8`, `XOVER_TDM_SLOT_MASK == 0x3F`.
   - Allocates TX master channel on `I2S_NUM_0` with `auto_clear = true`.
   - Initializes channel in TDM mode: `I2S_TDM_PCM_SHORT_SLOT_DEFAULT_CONFIG(I2S_DATA_BIT_WIDTH_32BIT, I2S_SLOT_MODE_STEREO, XOVER_TDM_SLOT_MASK)` with `total_slot = 8`, `ws_width = 1`, `ws_pol = true`, `bit_shift = true`. Clock source `I2S_CLK_SRC_DEFAULT` (160 MHz PLL). GPIOs from `board_config.h` (`XOVER_PIN_I2S_MCLK`, `XOVER_PIN_I2S_BCLK`, `XOVER_PIN_I2S_WS`, `XOVER_PIN_I2S_DOUT`).
   - Clock override: applies `i2s_ll_tx_set_mclk(I2S_LL_GET_HW(0), &div)` with integer 13, num 1, den 48 (160 MHz / (13 + 1/48) = 12.288 MHz) and `i2s_ll_tx_set_bck_div_num(I2S_LL_GET_HW(0), 1)` (bck_div = 1) before enabling, to guarantee MCLK = BCLK = 12.288 MHz without RX-clamping distortion.
2. `tdmout_start`:
   - Returns `ESP_ERR_INVALID_STATE` if not initialized or already running.
   - Calls `i2s_channel_enable()`.
3. `tdmout_stop`:
   - Returns `ESP_ERR_INVALID_STATE` if not initialized or not running.
   - Calls `i2s_channel_disable()`.
4. `tdmout_deinit`:
   - Stops if running, deletes channel with `i2s_del_channel()`, resets state.
5. `tdmout_write`:
   - Returns `ESP_ERR_INVALID_STATE` if not running.
   - Returns `ESP_ERR_INVALID_ARG` if `src` is NULL, `size_bytes == 0`, or `size_bytes` is not an integer multiple of 32 bytes (8 slots * 4 bytes).
   - Calls `i2s_channel_write()` with timeout converted via `pdMS_TO_TICKS()` (or `portMAX_DELAY` for `UINT32_MAX`).

**Rules:**
- Pins and frame parameters come only from `board_config.h` (S1).
- No magic numbers: frame size constant, clock div constants defined cleanly (C4).
- Real-time safety: no heap allocation, no logging, no unbounded loops in `tdmout_write` (R1).
- CODEOWNERS path: `firmware/components/tdmout/` (owned by `@rageshskutty`).
