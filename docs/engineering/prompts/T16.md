# T16 — SPSC audio frame ring

**Objective:** implement the bounded single-producer/single-consumer ring primitive used by audiosrc.
**Paths:** `firmware/components/audiosrc/audiosrc_ring.c`, `firmware/components/audiosrc/internal/audiosrc_ring.h`, `host/tests/test_spsc_ring.c`, host test registration only.
**Exact contract:**
```c
typedef struct { int32_t left, right; } audiosrc_frame_t;
typedef struct {
    audiosrc_frame_t *storage;
    size_t capacity;
    atomic_size_t head, tail;
} audiosrc_ring_t;
int audiosrc_ring_init(audiosrc_ring_t *, audiosrc_frame_t *storage, size_t capacity);
size_t audiosrc_ring_write(audiosrc_ring_t *, const audiosrc_frame_t *, size_t n);
size_t audiosrc_ring_read(audiosrc_ring_t *, audiosrc_frame_t *, size_t n);
size_t audiosrc_ring_count(const audiosrc_ring_t *);
```
Capacity is usable capacity (no empty sentinel slot), must be >=2 and <=SIZE_MAX/2. Caller owns storage for ring lifetime. One producer writes head; one consumer writes tail. Use C11 acquire/release atomics; no locks, allocation, blocking, logging, or wait loops. Read/write transfer up to available frames and return count immediately. Null/invalid init returns -1; invalid operation arguments return 0. Producer backpressure and bounded consumer waiting stay in the caller.
**Test:** `host/tests/test_spsc_ring.c` is committed but unregistered. Register it, confirm missing-function baseline failure, implement, then run focused test, host suite, `python tools/check.py`, ASan/UBSan. Verify empty/full, exact capacity, partial transfer, order, wraparound, count, null and invalid-capacity cases. No ESP-IDF or hardware.
**Size:** 30–80 handwritten production LOC. Do not change `audiosrc_push/pull` behavior here. Stop on >80 LOC, multi-producer requirements, or signature mismatch; three attempts maximum. Report commands/output honestly and diff only.
