# T24 — Bring-up tone generator

**Objective:** fill six planar channels with six distinct sine tones at a capped level, for the G1 six-tone test. Pure host logic; the I2S side is a later card.
**Paths:** `firmware/main/bringup_tone.h`, `firmware/main/bringup_tone.c`, `host/tests/test_bringup_tone.c`, host registration. Add `firmware/main` as an include dir of the test target. Link `m`.
**API (exact):**
```c
#define BRINGUP_TONE_CHANNELS 6U
#define BRINGUP_TONE_FS_HZ 48000U
#define BRINGUP_TONE_MAX_DBFS (-30.0f)
#define BRINGUP_TONE_MIN_DBFS (-120.0f)
extern const uint32_t bringup_tone_freq_hz[BRINGUP_TONE_CHANNELS]; /* {400, 700, 1100, 1700, 2300, 3100} */
int bringup_tone_fill(float level_dbfs, uint32_t start_frame, size_t n_frames,
                      int32_t *const channels[BRINGUP_TONE_CHANNELS]);
```
**Behavior, in this check order:** 1. Return -1 if `level_dbfs` is not finite, above -30.0 (AGENTS S3) or below -120.0. 2. If `n_frames == 0` return 0. 3. Return -1 if `channels` or any `channels[i]` is NULL. 4. Otherwise for channel `ch` and frame `i`, with `n = (uint64_t)start_frame + i`: `idx = (n * bringup_tone_freq_hz[ch]) % 48000`, sample = `lrintf(amp * sinf(2*pi*idx/48000))` with `amp = powf(10, level_dbfs/20) * 2147483647` (single precision only). Phase comes from the integer `idx`, never from an accumulating float. Nothing is written on a -1 return.
**Why those tones:** all six are whole cycles in one second, none is a multiple of another, so a one-second capture separates them exactly. They are the maintainer's G1 test inputs, not safety limits.
**Test:** committed but unregistered `host/tests/test_bringup_tone.c`. Register, confirm baseline failure, implement. Tolerances in the test: level within 0.001 dB, other tones at most 1e-5 of the wanted tone (-100 dB), bit-exact chunking and periodicity.
**Safety:** this card only produces samples. It does not start I2S and does not unmute anything. The -30 dBFS cap is enforced here and again by Kconfig `XOVER_BRINGUP_MAX_DBFS` in T26/T27.
**Size:** 30–60 production LOC. Not a `*_rt` file; it is called from the bring-up task, not the DSP task. Do not modify registered tests; full host suite and `python tools/check.py` stay green. Three attempts maximum; diff-only report.
