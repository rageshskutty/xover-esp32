# T07a5 — Compiled-node response evaluator

**Objective:** add a small internal evaluator for the existing compiled node representation; no graph walk or protection integration.
**Dependencies:** T07a4 is accepted; ADR 0011 and the internal response seam have maintainer/CODEOWNERS approval; existing `bnode_t` and `dsp_sos_eval` signatures match below. A committed bundle alone does not satisfy these review gates.
**Paths:** `firmware/components/dspgraph/dspgraph_response.c`, `firmware/components/dspgraph/internal/dspgraph_response.h`, `host/tests/test_node_response.c`, host and firmware CMake registration.
**Existing compiled-node types:** `typedef enum { K_INPUT, K_OUTPUT, K_CASCADE, K_GAIN, K_DELAY, K_POLARITY, K_MIX } bkind_t;` `typedef struct { char id[32]; bkind_t kind; dsp_cascade_t casc; float gain; float gains[8]; uint32_t delay; bool invert; } bnode_t;` `dsp_cascade_t` contains `dsp_sos_t sos[4]` and `uint8_t n`.
**Existing evaluator:** `dsp_err_t dsp_sos_eval(const dsp_sos_t *s, size_t n_sections, double fs_hz, double f_hz, double *re, double *im);` `DSP_OK` means success.
**Internal seam:** include `dspgraph_build.h` for `bnode_t` / `bkind_t`; declare `int dspg_node_response(const bnode_t *node, double fs_hz, double f_hz, double *re, double *im);` in the new internal header. Return 0 on success, -1 on null, unsupported kind, invalid frequency, SOS error, or non-finite result. Do not modify the existing compiled-node layout.
**Behavior:** input/output return 1+j0. Gain multiplies `re` and `im` by `node->gain` (already linear; 1.0 is identity). Polarity multiplies the response by -1 only when inverted. Delay uses `exp(-j*2*pi*f*delay/fs)`. Cascade makes one call to `dsp_sos_eval(node->casc.sos, node->casc.n, fs_hz, f_hz, re, im)`; that evaluator already rejects `n == 0`. The stored SOS denominator convention is `1 + a1*z^-1 + a2*z^-2`; `a1` and `a2` are used as stored and must not be negated again. Mix is unsupported; return -1 with outputs unchanged. Reject null pointers, non-finite/non-positive sample rate, non-finite frequency, frequency outside `(0, fs/2)`, empty/oversized cascade, and non-finite results. Leave both outputs unchanged on every failure.
**Committed test:** `host/tests/test_node_response.c` is unregistered. Register it and verify missing-function baseline failure, then implement. Cover identity, gain, inverted polarity, one-section cascade, delay phase, unsupported mix, null node/output pointers, zero/NaN/infinite sample rate, zero/Nyquist/NaN/infinite frequency, empty cascade, and non-finite gain/result. Assert output sentinels remain unchanged on each failure. For PEQ use the existing `host/tests/golden/rbj_eq.json` entry with type=peq, f0=1000 Hz, q=0.7, gain=-6 dB; its 1000-Hz magnitude is exactly -6.000003627305285 dB. Use the entry's SOS values under the denominator convention above and tolerance 0.001 dB; never regenerate or edit the golden.
**Regression:** run the committed T07a2 `test_protect.c` violation vector; it must remain rejected.
**Build:** existing C11 warning flags, focused test, host suite, `python tools/check.py`, ASan/UBSan. Production <=80 LOC. Stop if the golden fixture cannot be represented by `bnode_t` without changing its layout or if scope exceeds 80 LOC. Three attempts maximum.
