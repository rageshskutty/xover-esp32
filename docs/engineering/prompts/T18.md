# T18 — S7 gain-ramp duration helper

**Objective:** compute a safe sample count for a linear gain ramp used by start, stop, swap and fault paths. This helper does not perform audio processing.
**Authority:** AGENTS.md S7; 48 kHz from docs/design.md. Use existing `dsp_gain_set_target` to execute the returned ramp.
**Paths:** `firmware/components/dspblocks/dsp_s7_ramp.c`, `firmware/components/dspblocks/internal/dsp_s7_ramp.h`, `host/tests/test_s7_ramp.c`, host and component source registration.
**API:** `int dsp_s7_ramp_frames(float current, float target, uint32_t *frames);` Return 0 on valid arguments, -1 for null output, non-finite gains, or gains outside [0,1]. On failure leave `*frames` unchanged. Equal gains return 0 frames.
**Rule:** linear per-sample gain delta must be <=0.001 (a full-scale input step is therefore <= -60 dBFS). Ramp-up uses at least 960 samples (20 ms); ramp-down uses at least 240 (5 ms). Compute the delta in float32 exactly as written: `float delta = fabsf(target - current); uint32_t need = (uint32_t)ceilf(delta / 0.001f);` Return the greater of that count and the directional minimum. Do not compute this in double. Caller passes the result unchanged to `dsp_gain_set_target`. The helper does not decide whether an event is safe to begin.
**Numerical boundary:** all subtraction, absolute value, division, and ceiling use float32 (`fabsf`/`ceilf`) exactly as above. The per-sample bound is compared to the representable float constant `0.001f`; do not add an arbitrary decimal tolerance or change the safety gate. The test checks values immediately below and above the 240-sample threshold (`0.24f` and `nextafterf(0.24f, INFINITY)`) so float32 rounding cannot silently move the boundary.
**Test:** committed but unregistered `host/tests/test_s7_ramp.c`. Register and confirm expected missing-function baseline failure. Assert 0->1 and 1->0 yield 1000 samples; 0.5->0.75 gives 960; 0.5->0.1 gives 400; 0.1->0.099 gives 240; 0->0.24 gives 240; 0->nextafterf(0.24f, INFINITY) gives 241; check the implied step <=0.001f and invalid/equal cases.
**Build:** host suite and `python tools/check.py`, existing strict flags. Production 30–80 LOC. Do not change existing `dsp_gain_t` layout or weaken S7. Three attempts maximum; report unrun checks honestly.
