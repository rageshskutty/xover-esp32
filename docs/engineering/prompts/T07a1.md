**API (fixed):**
```c
typedef struct { char out_id[32]; float max_gain_db;
 float stop_below_hz, atten_below_db, stop_above_hz, atten_above_db; } dspg_protect_t;
typedef struct { char out_id[32]; double frequency_hz; double response_db; } dspg_protect_failure_t;
int dspg_protect_check(const dspg_protect_t *records, size_t n_records,
 const char *const *output_ids, size_t n_outputs, const double *frequency_hz,
 const double *const response_db_by_output[], size_t n_frequencies,
 dspg_protect_failure_t *failure);
```
**Exact behavior:** return 0 only if every output has exactly one valid record and all samples pass. Return -1 on malformed/null/mismatched input. Finite frequencies strictly increase. Record ID is NUL-terminated within 32 bytes. max_gain [-120,+24] dB. Edge is zero-disabled or [10,20000] Hz; disabled attenuation must equal 0; enabled attenuation [0,120] dB. Lower applies f<=edge, upper f>=edge. Compare response_db > limit (equality passes). Visit outputs in given order and samples ascending. On success zero the failure struct. On malformed record failure, frequency=0,response=0. Do not use NaN as sentinel.
**Tests first and expected values:** passthrough 0 dB accepts max=0; rejects max=-1. Gain -6.020599913 dB passes max=-6.020599913 within 1e-5. Lower edge=100, attenuation=20 rejects 10 and 100, accepts 100.01 if max permits. Upper edge=1000 rejects 1000 and 20000, accepts 999.99. Edge=0 with attenuation=0 skips only that band. Also reject just-over ceiling (+0.00001), missing/duplicate/unknown ID, NaN/Inf, null mismatch, descending/duplicate frequency, malformed unterminated ID, and disabled attenuation nonzero. No golden regeneration.
