# T07a1 — Protection record validator

Objective: implement shared field and record-set validation for device protection records. This card owns validation; the comparator card calls it.
Dependencies: T07a0 is accepted and dspg_protect_t is present; CODEOWNERS contract approval before merge.
Paths: firmware/components/dspgraph/dspgraph_protect.c, firmware/components/dspgraph/internal/dspgraph_protect.h, host/tests/test_protect_record.c, host test registration only.
Internal APIs: declare int dspg_protect_fields_valid(const dspg_protect_t *r); and int dspg_protect_record_valid(const dspg_protect_t *records, size_t n_records, const char *const *output_ids, size_t n_outputs);. Both return 1 when valid, else 0. Keep both internal; no other public API.
Field rules: reject null, empty or unterminated IDs (NUL within 32 bytes required), and non-finite values. max_gain_db is [-120,+24]. Each edge is exactly 0 (disabled) or [10,20000] Hz. Enabled attenuation is [0,120]; disabled attenuation must equal 0.0f. Do not add driver-specific limits.
Set rules: require non-null pointers, nonzero output count, equal record/output counts before reading either array, unique non-empty NUL-terminated output IDs, and an exact one-to-one mapping. Call fields_valid on every record, then reject duplicate, unknown, or missing IDs.
Test: host/tests/test_protect_record.c is committed but unregistered. Register, confirm missing-function baseline failure, then implement. Every rejection vector has a corresponding valid boundary/nearby vector differing in one field. Cover bounds, all disabled-band combinations, empty/31-byte/unterminated ID (unterminated case must match the output ID's first 31 bytes), duplicate/missing/unknown, NaN/Inf. Keep production implementation <=80 LOC; if validation exceeds that, stop and split.
Build: focused test and full host suite under C11 -Wall -Wextra -Wconversion -Werror, python tools/check.py, and ASan/UBSan. Do not claim unrun checks.
Stop: type/header mismatch, unclear bounds, public API expansion, or >80 LOC. Three attempts maximum; diff-only report.
