# T07a2 — Protection curve comparator

Objective: implement ADR 0010's pure comparator. This is host-testable C; no graph traversal, persistence, JSON, ESP-IDF, or hardware.
Dependencies: T07a1 validator implementation is present; ADR 0010 comparator contract approved for planning.
Paths: firmware/components/dspgraph/dspgraph_protect.c, firmware/components/dspgraph/internal/dspgraph_protect.h, host/tests/test_protect.c, host test registration only.
API: typedef struct { char out_id[32]; double frequency_hz; double response_db; } dspg_protect_failure_t; int dspg_protect_check(const dspg_protect_t *records, size_t n_records, const char *const *output_ids, size_t n_outputs, const double *frequency_hz, const double *const response_db_by_output[], size_t n_frequencies, dspg_protect_failure_t *failure);
Behavior: reject null pointers, zero dimensions, unequal record/output counts, invalid records/IDs via dspg_protect_record_valid, non-finite or non-strictly-increasing frequencies, and null/non-finite samples. Validate the entire input before comparing any protection limit. Compare outputs in supplied order and frequencies ascending. max_gain_db applies everywhere. Lower band applies when f<=stop_below_hz and response_db > -atten_below_db; upper applies when f>=stop_above_hz and response_db > -atten_above_db. Equality passes. Return 0 on success and zero every failure field. Return -1 on malformed input and zero the failure struct. For a valid limit violation return -1 with the first violating output ID, frequency, and response. No NaN sentinel.
Test: host/tests/test_protect.c is committed but unregistered. Register it; confirm missing comparator baseline failure, then implement. Preserve all malformed-record, validate-all-before-compare, bijection, ordering, and golden vectors. Keep production comparator <=80 LOC; validation is delegated to T07a1.
Build: focused test and host suite with C11 -Wall -Wextra -Wconversion -Werror, python tools/check.py, and ASan/UBSan. Report only commands actually run.
Stop: signature mismatch, public API expansion, or >80 LOC. Three attempts maximum; diff-only report.
