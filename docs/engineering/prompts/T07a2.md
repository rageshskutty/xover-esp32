# T07a2 — Protection record validator

**Objective:** implement only the internal record-set validator described below.
**Dependencies:** T07a1 implementation is present and its `dspg_protect_t` and internal header are unchanged.
**Paths:** `firmware/components/dspgraph/dspgraph_protect.c`, `firmware/components/dspgraph/internal/dspgraph_protect.h`, `host/tests/test_protect_record.c`, host test registration only.
**Public type:** use `dspg_protect_t` from public `dspgraph.h`: `typedef struct { char out_id[32]; float max_gain_db; float stop_below_hz, atten_below_db; float stop_above_hz, atten_above_db; } dspg_protect_t;` Include both headers.
**API:** `int dspg_protect_record_valid(const dspg_protect_t *records, size_t n_records, const char *const *output_ids, size_t n_outputs);` It returns 1 for valid, 0 for invalid. Require `n_records==n_outputs` before reading records. Keep it internal; do not change `dspgraph.h` or other public APIs.
**Rules:** reject NULL pointers, zero outputs, empty or unterminated IDs (NUL must occur within 32 bytes), duplicate IDs, unknown/missing IDs, and non-finite fields. Each output ID maps to exactly one record and vice versa. `max_gain_db` is [-120,+24]. Each edge is exactly 0 (disabled) or [10,20000] Hz. Enabled attenuation is [0,120]; disabled attenuation must equal 0.0f. Do not add driver-specific limits.
**Committed test:** `host/tests/test_protect_record.c` is unregistered. First add one test registration, verify it fails against the existing T07a1 baseline because the function is absent, then implement. Cover bounds, one-step-outside values, empty/31-byte/unterminated ID, duplicate/missing/unknown, all four disabled-band combinations, NaN/Inf. Keep production code <=80 LOC.
**Regression:** keep the T07a1 comparator violation/malformed-record vectors passing.
**Build:** follow existing host C11 warning flags; focused test, host suite, and `python tools/check.py`. Run ASan/UBSan. Record baseline and final output; do not claim unrun checks.
**Stop:** mismatched T07a1 header/type, public API change, unclear boundary, or >80 LOC. Three attempts maximum. Diff-only report.
