# T17 — Pure TDM slot packer

**Objective:** pack six planar output channels into each eight-word TDM frame; this is host logic only and does not configure I2S or DACs.
**Paths:** `firmware/components/tdmout/tdm_pack.c`, `firmware/components/tdmout/internal/tdm_pack.h`, `host/tests/test_tdm_pack.c`, host and component source registration.
**API:** `int tdm_pack_8slot(const int32_t *const channels[6], size_t n_frames, int32_t *interleaved, size_t out_words);`
**Layout:** slot 0 L woofer, 1 L tweeter, 2 R woofer, 3 R tweeter, 4 sub A, 5 sub B, 6 zero, 7 zero. Input arrays are planar and each has `n_frames` words. Output is frame-major, eight `int32_t` words per frame. No byte swap or scaling.
**Errors:** return 0 on success; -1 for null required pointers, insufficient `out_words`, or size multiplication overflow. Validate all arguments before writing so output is unchanged on failure. `n_frames==0` succeeds and touches no buffers.
**CODEOWNERS regression:** the full host suite must retain the existing `test_graph_validate` check that `configs/invalid/duplicate_slot.json` is rejected (`E_SLOT`). Do not weaken or replace it.
**Test:** committed but unregistered `host/tests/test_tdm_pack.c`. Register and confirm missing-function baseline failure, implement, then run focused test, host suite and `python tools/check.py` under existing warning flags. Verify two frames with distinct values in all six channels, zero pad slots, planar-to-interleaved order, zero frames, nulls, insufficient capacity and unchanged output on failure.
**Size:** 30–80 production LOC. No pins, device registers, or ESP-IDF. Stop if channel mapping differs from docs/design.md; never guess a hardware mapping. Three attempts maximum; report exact commands/results and diff only.
