# T25 — PCM5122 control over an injected bus, and status decode

**Objective:** run the T23 init sequence through a caller-supplied I2C write function, and decode the DAC's own clock and state registers so bring-up can check the clocks without a scope. Host logic only; the real I2C bus is T26.
**Depends on:** T23 merged.
**Paths:** `firmware/components/pcm5122/internal/pcm5122_ctl.h`, `firmware/components/pcm5122/pcm5122_ctl.c`, `host/tests/test_pcm5122_ctl.c`, host and component registration.
**Datasheet source (S1):** SLAS763C Table 104 (Reg 0x5B: DTFS bits 6:4, DTSR bits 3:0), Tables 105 and 106 (Regs 0x5C bit 0 and 0x5D: BCK ratio, 9 bit), Table 108 (Reg 0x5F: LTSH bit 4, CKMF bit 2, CSRF bit 1, CERF bit 0), Table 111 (Reg 0x72: MTST bits 1:0), Table 113 (Reg 0x76: BOTM bit 7, PSTM bits 3:0).
**API (exact):**
```c
typedef int (*pcm5122_write_fn)(void *ctx, uint8_t addr7, uint8_t reg, uint8_t val); /* 0 = ok */
typedef int (*pcm5122_read_fn)(void *ctx, uint8_t addr7, uint8_t reg, uint8_t *val);  /* 0 = ok */
typedef struct { pcm5122_write_fn write; pcm5122_read_fn read; void *ctx; } pcm5122_bus_t;
typedef struct { uint8_t fs_class; uint8_t sck_ratio_code; uint16_t bck_per_frame;
                 uint8_t clock_error; uint8_t power_state; uint8_t xsmt_level; } pcm5122_status_t;
int pcm5122_ctl_init_tdm(const pcm5122_bus_t *bus, uint8_t addr7, uint32_t offset_bck);
int pcm5122_ctl_read_status(const pcm5122_bus_t *bus, uint8_t addr7, pcm5122_status_t *out);
int pcm5122_status_is_running_48k_tdm(const pcm5122_status_t *st);
```
**Behavior:** `init_tdm` returns -1 with no bus access if `bus`, `bus->write` is NULL, `addr7` is outside 0x08..0x77, or T23 rejects the offset; otherwise it issues the three T23 writes in order and returns -1 at the first write that returns non-zero, without issuing the rest. `read_status` returns -1 with no bus access on a NULL `bus`, `bus->read`, `out` or an address outside 0x08..0x77; otherwise it reads, in this order, 0x5B, 0x5C, 0x5D, 0x5F, 0x76, 0x72 and returns -1 at the first failing read, leaving `*out` unchanged. Decode: `fs_class = (r5B>>4)&7`, `sck_ratio_code = r5B&0xF`, `bck_per_frame = ((r5C&1)<<8)|r5D`, `clock_error = 1 if (r5F & 0x05) else 0`, `power_state = r76&0xF`, `xsmt_level = r72&3`. `pcm5122_status_is_running_48k_tdm` returns 1 only for `fs_class==3 && sck_ratio_code==6 && bck_per_frame==256 && clock_error==0 && power_state==5`, else 0 (including NULL). No sleeping, no retries, no logging.
